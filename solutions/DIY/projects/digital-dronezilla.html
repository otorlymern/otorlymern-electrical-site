Digital Dronezilla

Design concept · source lacks complete construction details

← Back to DIY Audio & Video Projects

Description

A four-voice just-intonation drone concept. The article explains combining a reference frequency, phase-locked loops, and programmable binary division to derive related pitches; it includes a programming truth table.

Open original source PDF ↗

Materials
  • Stable reference oscillator
  • Four PLL-based multiplier paths; the article discusses the CD4046
  • Programmable binary divider devices; the article cites the National 6281
  • Logic-level load switches for the divider inputs
  • Oscilloscope or frequency counter and current-limited bench supply
Step-by-step guide
  1. Treat the article as an architecture brief.

    The one-page source does not include a complete schematic or BOM. Do not wire a replica from the block diagram alone.

  2. Recreate the frequency-ratio table.

    Use the source truth table to list each binary load state and its intended output interval before selecting modern parts.

  3. Prototype one voice path.

    Research a suitable PLL and programmable divider pair, then build a single path from reference input to divided output using their current datasheets.

  4. Measure before duplicating.

    Check lock range, output frequency, logic thresholds, and tuning stability with a counter/scope. Only after one path works should you consider repeating it for four voices.

  5. Add programmable loads and mix.

    Use the source table to select load states and combine outputs through an appropriate audio interface. This stage needs a newly verified schematic.

The archive source is a conceptual article, not a complete build article. The named divider is a legacy part; this guide deliberately does not invent substitute wiring or a complete BOM.
