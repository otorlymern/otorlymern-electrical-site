Pulse Width Multiplier

Voltage-controlled digital audio circuit

← Back to DIY Audio & Video Projects

Description

Four comparator pulse streams are combined through exclusive-OR logic. A triangle input becomes a moving group of pulse widths, producing changing harmonic content and, at some settings, additional pulses per cycle.

Open original source PDF ↗

Materials
  • Use the original scanned schematic and parts list for exact resistor/capacitor values
  • Four comparator channels, op-amp summing stages, and 4030 or 4070 CMOS EX-OR logic as described
  • Input/output jacks, controls, board, regulated supply appropriate to the chosen op amp
  • Triangle-wave source, adjustable control voltages, oscilloscope, and audio monitor
Step-by-step guide
  1. Map the circuit blocks.

    Mark the triangle input, comparator channels, three control-voltage summers, and EX-OR outputs before assembly.

  2. Build and test the comparator section.

    Follow the original schematic, observe op-amp pinout, and confirm each comparator produces the expected pulse stream before connecting the logic mixer.

  3. Add the EX-OR stages.

    Use the stated 4030 or 4070 option and verify each output separately. The article describes the outputs as successively combining more pulse streams.

  4. Set the input and control ranges.

    Choose the resistor scaling for the signal and CV range in the article’s table. Do not copy one range’s Ra/Rb values into another setup.

  5. Calibrate the signal scaling.

    Use an oscilloscope to set the specified peak-to-peak range and offset for your CV system. Adjust R5 so the first comparator produces the intended square/pulse wave.

  6. Patch and explore.

    Connect a triangle oscillator and gradual CV sources. Begin with one CV input, then add the others while watching pulse density and checking output level.

The one-page scan is image-based and the OCR cannot reliably recover every BOM value. Confirm each component value visually from the source scan before ordering or building.
