Eric Valinsky · Synapse · July/August 1977

Electrophony

Patch study · not a parts-level kit

← Back to DIY Audio & Video Projects

Description

“Techniques of Electrophony” asks whether perceived voices must correspond to separate keyboard voices. Eric Valinsky contrasts independent polyphonic parts with homogeneous chordal playing, then offers ways to create ambiguous, layered textures with fewer sources.

Source scope: the original OES extract contains printed p. 28 only, but the complete article continues on printed p. 29. Both pages have now been checked in the full July/August 1977 issue of Synapse (PDF pages 30–31). This guide covers the complete two-page article, including balanced modulation, rotating tape echo, polyphonic voice assignment and the conclusion. The author credit is Eric Valinsky.

This is a patch/perception study, not an electronic construction project. No component values, power supply, module circuits, keyboard interface or complete tape-echo build are given.

Step-by-step guide

1. Read Figure 1 as separate audio and control paths

VCF 1 and VCF 2 outputsSeparate mixer inputs → outputCombine the two filtered voices.
Common clockBoth sample-and-hold trigger inputsCoordinates when random values are sampled.

2. Establish the patch one branch at a time

  1. Lower monitoring level. Confirm each VCO is audible on its own, tune both to bass frequencies, then tune them an octave apart. The source supplies no absolute fundamental frequency or waveform prescription beyond the drawing.
  2. Route VCO 1 through VCF 1 and VCO 2 through VCF 2. Test the filters manually at modest resonance before adding modulation.
  3. Patch each noise source to its sample-and-hold signal input; patch the common clock to both trigger inputs. Send each held output to its own VCF frequency-control input using the actual modules’ compatible CV range. Begin with modest modulation depth.
  4. Bring filter resonance close to, but not into uncontrolled self-oscillation. Raise monitor level only after checking the resulting peaks. Two strongly resonant filters can produce unexpectedly loud output.
  5. Monitor each branch alone, then both together. Listen for a fundamental and moving overtones rather than counting hardware voices as musical parts. The point is that a listener may hear one, two, three or four groupings from the same two-branch patch.
  6. Record a passage and listen again without looking at the patch. Note perceived layers, clock rate, relative source levels, resonance and filter ranges. These observations are a repeatability exercise, not a guaranteed psychoacoustic outcome.

3. Further techniques across printed pages 28–29

Fast pitch sequencing

A single rapidly sequenced sound can suggest several interleaved voices when pitches are chosen to form perceptual groups. Start slowly to establish a note list, then vary speed and spacing and listen for separate registers or contours. The article does not print a sequence, BPM or tuning table, so this is a composition experiment rather than a reproducible preset.

Several nearly matched slow square waves

The article proposes multiple sub-audio square waves controlling a source’s discrete pitches; slightly different rates produce long evolving rhythmic patterns. It does not show how their voltages are combined. Use an existing compatible CV mixer/control implementation; never connect several active outputs together with a passive splitter to invent the missing summing stage.

Balanced modulation / simulated chordal texture

The printed example puts a fixed sine, suggested as C above middle C, into one balanced-modulator input and a pitch-controlled waveform into the other; it cites Ronald Pellegrino using a live soprano. Monitor both original signals and the processed signal together. The recovered continuation on p. 29 completes the claim: suitable pitch choices for the variable source produce a limited set of four-note chords. It does not supply a chord chart, exact pitch sequence or calibrated modulator settings. Explore the variable source slowly while holding the fixed sine steady, recording useful combinations; this is not a promise that every input pitch yields a conventional chord.

Figure 2: quad rotating tape echo

The continuation explains Figure 2 through Valinsky’s work A Clarinet, After an Eventful Night Out, Returns Home, for clarinet and ARP 2600. A four-channel tape recorder operates with every channel recording and the playback head monitored. The inter-channel routing is a feed-forward chain, not a recirculating feedback loop: playback of channel 1 feeds record input 2, playback 2 feeds record input 3, and playback 3 feeds record input 4. No connection returns the final stage to the first input. The article describes four occurrences of the original sound followed by silence, with a choice of a mixed result or rotating quad presentation.

Live monitoring matters: the four speaker symbols in Figure 2 are not the four delayed playback outputs. Speaker 1 monitors the incoming, undelayed signal; speakers 2, 3 and 4 monitor playback channels 1, 2 and 3 respectively. The prose distinguishes this live setup from the recording arrangement using the fourth channel. Monitoring only delayed returns in live performance would displace the apparent original event in time. Preserve that distinction rather than silently substituting four playback taps.

  1. Before patching, confirm that the actual recorder supports record/playback monitoring and individually accessible channels. Use its own documentation for operating modes and signal levels. This is an external routing study, not permission to modify tape-head or mains wiring.
  2. At low levels, establish one record-to-playback path and measure/listen to its delay. Only then add each successive playback-to-next-record connection. Do not route the last playback signal back to the source; the source explicitly calls for no feedback.
  3. Test with an isolated short sound, then stop the input. Monitor the direct signal and first three delayed stages at the marked live positions. Confirm the sequence ends rather than regenerating indefinitely. Log the actual delays; the article specifies no tape speed or head spacing.
  4. For a recorded mix, distinguish track recording from the monitoring bus and preserve the fourth-channel arrangement in Figure 2. Make a short test recording and listen back before committing a performance. A software or digital multi-delay recreation must be labeled an adaptation, with its own explicit routing and times.

The complete article supplies the operating principle and monitoring explanation, but still no tape-machine electronics, alignment procedure, gain calibration or mechanical build plan. Consult the original Figure 2 before adapting a particular recorder.

Different sounds across polyphonic voices (p. 29)

The last example deliberately uses a polyphonic synthesizer: set each physical voice differently, then play several keys. Voice allocation can associate a given key with different timbres in a more-or-less unpredictable way. The variation comes from key-to-voice assignment rather than a requirement for a new oscillator per perceived musical part.

For a practical comparison, record repeated chords with all voices alike, then repeat with distinct settings on each voice. Observe which notes acquire which sounds as allocation changes. The assignment algorithm and reset behavior belong to the actual instrument; the article does not prescribe them or guarantee randomness. Keep levels matched so loudness alone does not explain the result.

The article’s conclusion

Valinsky extends electrophony beyond pitched analog patches to musique concrète and studio techniques. Results may be pitched or unpitched, predictable or unpredictable, deterministic or stochastic, recorded or real-time. His argument is for inventive, efficient use of the available technology, not an absolute rejection of polyphonic instruments—the final example expressly uses one.
