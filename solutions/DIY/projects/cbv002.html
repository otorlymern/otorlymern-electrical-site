CBV002 Circuit-Bent Video Delay

Eurorack video module construction and calibration

← Back to DIY Audio & Video Projects

Description

A 16 HP analog video delay adaptation that shifts horizontal position and hue. The guide covers main and control boards, an optional power-supply board, modifications, enclosure assembly, and visual calibration. Specified draw is 120 mA at +12 V and 60 mA at -12 V.

Open original source PDF ↗

Materials
  • CBV002 main board and control board with the version-matched interactive BOM
  • Optional Syntonie PSU board and components if building that supply
  • R72/R73 modification resistors if following the documented output-offset fix
  • 16-pin Eurorack cable, video input/output cables, enclosure/front panel, and mounting hardware
  • Current-limited bench supply, multimeter, video test pattern, monitor/capture device
Step-by-step guide
  1. Check board revision, BOM, and supply choice.

    Decide whether using the optional on-board PSU. Confirm the board versions and component placement files before assembly.

  2. Populate the main board.

    Follow the guide’s order: resistor/resistor array, diodes, ferrite beads, capacitors, transistors/regulators, sockets/ICs, trimmers, then connectors. Check polarity and array orientation.

  3. Build the control board.

    Populate its resistors, capacitors, ICs, and controls in the guide’s order. Inspect both boards before interconnecting.

  4. Install the documented R72/R73 modification if desired.

    The guide places these resistors between specified U4 pins because the main board has no footprints. Prevent leads from shorting. The guide says omitting them can leave DC output and raise current when no RCA input is connected.

  5. Verify power before video testing.

    For the optional supply, apply 15 VDC and check +12 V and -12 V at the correct power connector pins. Then connect the boards and confirm video passes.

  6. Calibrate blanking and delay.

    Use a test pattern and VCO vertical range to adjust P1/P2 until bars span the display. Adjust delay for color match, then P3 for delayed-signal brightness as shown in the guide.

  7. Assemble the enclosure and recheck.

    Install boards and panel per the enclosure drawings. Recheck connector and power orientation before final use.

The calibration instructions use visual test patterns and the PDF’s photographs. Follow the exact board revision and connector pinout; do not infer calibration trimmer locations from text alone.
