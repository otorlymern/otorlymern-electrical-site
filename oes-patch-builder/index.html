Draw a modular synth patch before the cables move

The OES Patch Builder is a free browser tool for sketching, explaining, and preserving modular synthesizer signal flow. Add sound sources, audio modifiers, control-voltage sources, and CV modifiers; connect their ports; then export the finished diagram as a PNG for a notebook, session log, lesson, or repair record.

A simple patch-documentation workflow

  1. Click or drag a module symbol onto the patch canvas.
  2. Select two compatible nodes to draw a cable between them.
  3. Use blue connections for control voltage, red connections for audio, and yellow connections for trigger, gate, pulse, clock, reset, or sync signals.
  4. Select a symbol and press Delete or Backspace to remove it.
  5. Select the text option to add a text box to your patch page, allowing more specific labeling and other helpful notes for future you. Double click to edit the text box, click and drag to move it.
  6. Export the completed patch as a PNG before repatching the instrument.
